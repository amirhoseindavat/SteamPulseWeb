## About SteamPulse Web

SteamPulse Web is a web-based Open-Source companion for Steam users, designed to make discovering games, checking regional prices, and comparing purchase options easier.

Whether you're looking for the best regional price, checking DLC and bundle costs, exploring Steam sales, or keeping track of your Steam library, SteamPulse brings the information together in one place.

**SteamPulse Web is built to help gamers make better purchasing decisions.**

🌐 **Website:** [SteamPulse.ir](https://steampulse.ir)

## Features

### 🎮 Game Search & Discovery

- Search Steam games by name, AppID, or Store URL.
- Dedicated pages for individual Steam games.
- Explore popular and trending games.
- Browse Steam Top Sellers and Free Games.
- Discover upcoming releases and pre-orders.
- Explore Steam sales and themed events.

### 💰 Regional Pricing

- Compare game prices across different Steam regions.
- View regional pricing and currency information.
- Calculate estimated game key costs.
- Explore Steam packages, bundles, and other purchase options.
- Check DLC prices and discount percentages.

### 👤 Steam Profile Integration

- Connect and explore Steam profiles.
- View owned games and wishlists.
- Check account information and profile statistics.
- Explore recently played and currently playing games.

### 🧩 Additional Features

- Steam event and promotional banners.
- Game franchise information.
- Steam Deck compatibility information.
- ProtonDB and PCGamingWiki integration.
- Dark and light themes.
- Responsive interface for desktop and mobile devices.

### 🧩 SteamPulse Connect

SteamPulse also includes a companion browser extension that connects Steam and SteamDB browsing experiences with SteamPulse.

The extension is designed to make opening games in SteamPulse and accessing related information easier.

## Usage

1. Open [SteamPulse Web](https://steampulse.ir/).
2. Search for a game using its name, AppID, or Steam Store URL.
3. Select your preferred Steam region.
4. Explore game information, regional prices, DLCs, bundles, and purchase options.
5. Compare available options and make a smarter purchasing decision!

## Getting Started

To run SteamPulse Web locally, follow these steps.

### Prerequisites

- [Node.js](https://nodejs.org/) (20.x recommended)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amirhoseindavat/SteamPulseWeb.git
   ```

2. Navigate to the project directory:

   ```bash
   cd SteamPulseWeb
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development environment:

   ```bash
   npm run dev
   ```

The development command starts both the frontend and backend services.

### Build

To create a production build:

```bash
npm run build
```
